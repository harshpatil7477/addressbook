# Address Book Management System

## Project Overview

The **Address Book Management System** is a menu-driven application developed in **C programming** to store and manage contact information efficiently. The application allows users to add, search, edit, delete, list, and save contacts. It also performs validation for names, phone numbers, and email addresses to maintain valid contact data.

## Features

- Add a new contact
- Search for contacts
- Edit existing contact details
- Delete contacts
- Display all contacts
- Save contacts to a file
- Validate name, phone number, and email
- Prevent duplicate phone numbers and email addresses
- Menu-driven user interface
- File handling for storing contact information

## Technologies Used

- **Programming Language:** C
- **Concepts:** Structures, Arrays, Pointers, Functions, Strings
- **Data Handling:** File Handling
- **Build Tool:** Makefile
- **Platform:** Linux / WSL
